# NIGHT CASINO — Telegram Mini App

Полностью виртуальное казино внутри Telegram. Игровая валюта — внутренние виртуальные средства. Реальных денег, пополнений и выводов в приложении нет.

## Стек

- Node.js + Express
- Socket.IO
- Grammy для Telegram-бота
- HTML/CSS/JavaScript без отдельного frontend-фреймворка
- Local JSON storage (`data/db.json`)
- Курсы виртуальных валют через Frankfurter API с сохранённым fallback-кэшем

## Игры

1. Слоты — серверный результат, последовательная остановка барабанов, payline и win/loss effects.
2. Dice — серверное число 1–100, проверка режима и допустимого target.
3. Coinflip — серверный результат heads/tails с корректной победной/проигрышной анимацией.
4. Blackjack — настоящая колода 52 карты, Hit, Stand, Double, натуральный Blackjack 3:2, автоматическое завершение при 21 после Hit.
5. Roulette — европейская рулетка 0–36, проверка ставок на цвет/чётность/число.
6. Mines — 20 клеток, ровно 8 мин (40%), последовательное открытие, расчёт множителя по фактическому числу безопасных ходов, Cashout.
7. Crash — серверный live-round с `startedAt/crashAt`, ручным Cashout и Auto Cashout. Сервер никогда не доверяет множителю от клиента.
8. Wheel — серверный взвешенный сектор и синхронизированная анимация вращения.

## Исправления безопасности и логики

- Убрана возможность передавать произвольный Mines multiplier.
- Убрана возможность передавать поддельный Crash multiplier.
- Dice target ограничен диапазоном 1–100.
- Roulette ставки валидируются на сервере.
- Coinflip side валидируется на сервере.
- Blackjack после Hit до 21 автоматически доводит раунд до завершения; активная раздача не зависает.
- Добавлено действие Double с отдельным серверным endpoint и двойным резервированием ставки.
- Mines используют ровно 8 уникальных мин из 20; состояние хранится как массивы и не теряется при JSON persistence.
- Добавлены `/api/mines/status` и `/api/crash/status` для восстановления активного раунда после закрытия экрана.
- Crash cashout рассчитывается только по серверному времени.
- Комнаты принимают только поддерживаемые игры.
- Для старта общего раунда все игроки со ставками должны быть готовы.
- Ставки комнаты возвращаются при выходе игрока.
- Поддерживается несколько Socket.IO-соединений одного пользователя без преждевременного возврата ставки.
- Чат и серверные имена не вставляются в DOM как непроверенный HTML.
- Авторизация Telegram защищена проверкой `initData`; некорректный JSON в `user` больше не приводит к исключению.
- Добавлен простой rate limit на HTTP-запросы.
- `data/db.json` записывается атомарно через временный файл и безопасно восстанавливается после повреждения.
- `.env.example` полностью очищен от секретов.

## Анимации

Все 8 игровых экранов используют motion-концепцию NIGHT CASINO GAME MOTION LAB: anticipation → action → reveal → result.

Отдельно синхронизированы с серверными результатами:

- Slots: барабаны останавливаются по очереди; результат комбинации определяет эффект.
- Dice: бросок завершается серверным числом; победа/проигрыш зависит от `meta.win`.
- Coinflip: сторона монеты и эффект берутся из серверного результата.
- Blackjack: карты появляются поэтапно; reveal дилера соответствует итоговой раздаче.
- Roulette: анимация вращения всегда завершается отображением фактически выпавшего числа.
- Mines: открывается именно выбранная пользователем клетка; при проигрыше показывается реальное расположение 8 мин.
- Crash: live multiplier рассчитывается от серверного времени; Cashout останавливает раунд.
- Wheel: конечный сектор соответствует серверному `sector`.

## Запуск

1. Установить Node.js 20+.
2. Выполнить `npm install`.
3. Скопировать `.env.example` в `.env` и добавить собственные значения.
4. Запустить `npm start`.
5. Открыть `http://localhost:3000` для локальной проверки.
6. Для Telegram Mini App использовать HTTPS-адрес в `WEB_APP_URL`.

В development-режиме доступен demo-пользователь через обычный запуск Mini App без Telegram `initData`. В production авторизация только через Telegram `initData`.

## Проверка

`npm run check` проверяет синтаксис server/client.

Локальный API smoke-test для исправленной сборки проверяет:

- авторизацию;
- все 5 instant-игр;
- серверную валидацию Dice/Coinflip/Roulette;
- точное количество мин 8/20;
- Mines Cashout;
- Crash Cashout и защиту от поддельного множителя;
- Blackjack Hit до 21;
- Blackjack Double;
- историю;
- комнаты и запрет неподдерживаемой игры.

В окружении разработки этот smoke-test завершён успешно.


## Работа в Telegram-группе

`/start` в группе обрабатывается ботом NIGHT CASINO как отдельная команда и показывает кнопку `🎰 Открыть казино`. Обычные сообщения участников группы бот этим обработчиком не обрабатывает.

Другие боты в той же группе могут также отвечать на `/start`, если их собственные обработчики это позволяют. Это нельзя отключить из кода NIGHT CASINO; для ненужных ботов используется их настройка Group Privacy в BotFather.
